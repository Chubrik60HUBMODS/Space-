Вопросы

Коротко о главном

Это правда бесплатно?
Да. Ни рекламы, ни встроенных покупок, ни регистрации. Игра целиком лежит в одном файле и работает локально.
Нужно ли что-то устанавливать?
Нет. BarrelClicker.exe — самодостаточный файл: внутри уже есть .NET-рантайм и сама игра. Просто запусти его.
Почему Windows предупреждает о файле?
Приложение не подписано цифровым сертификатом — он стоит денег и для маленького проекта не обязателен. SmartScreen показывает предупреждение для любых неподписанных .exe. Нажми «Подробнее» → «Выполнить в любом случае».
Где хранится прогресс?
В папке %LOCALAPPDATA%\BarrelClicker\profile\. Сохранение происходит автоматически. Если удалить эту папку, игра начнётся заново.
Нужен ли интернет?
Нет. Игра полностью офлайн: считает доход, сохраняет прогресс и не отправляет никакие данные.
Есть ли админ-панель?
Да, для экспериментов: меню ☰ → Настройки → Открыть админку. Пароль по умолчанию — admin, его можно сменить. Там можно выдать себе скрап, бочки и улучшения.
Это мод или чит для чужой игры?
Нет. Barrel Clicker — полностью собственная игра, написанная с нуля: HTML/CSS/JS внутри окна Windows. Никаких чужих ассетов и серверов.
